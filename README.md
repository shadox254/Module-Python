# Module-Python
 
A collection of Python exercises organized by modules, covering progressively more advanced concepts.
 
## 📄 Description
 
This repository contains a series of learning modules (`Module-00` to `Module-10`), each focused on specific Python concepts and exercises, plus an additional `Module-00-C`.
 
## 🗂️ Project structure

- `Module-00/` — basics
- `Module-00-C/` — module 00 but it's C
- `Module-01/` — module 01 exercises
- `Module-02/` — module 02 exercises
- `Module-03/` — module 03 exercises
- `Module-04/` — module 04 exercises
- `Module-05/` — module 05 exercises
- `Module-06/` — module 06 exercises
- `Module-07/` — module 07 exercises
- `Module-08/` — module 08 exercises
- `Module-09/` — module 09 exercises
- `Module-10/` — module 10 exercises
## ▶️ Usage
 
Each module contains its own exercises. Navigate to the module folder and run the relevant Python script:
 
```bash
cd Module-XX
python3 script_name.py
```
